API CONTRACT: Same-origin backend endpoints (no hardcoded localhost for deployed phone browser):
POST /api/game/start JSON {"player_name":"name"} returns game_id and game state.
GET /api/game/{game_id} returns current game state.
POST /api/game/{game_id}/location JSON {"latitude":float,"longitude":float,"accuracy":float} returns updated state.
POST /api/game/{game_id}/reset returns fresh state.
GET /api/health returns service status.
Example state fields: game_id, player_name, phase, reached_checkpoints (array of numbers), deadline (ISO 8601 UTC or null), seconds_remaining, boosts (object keyed by checkpoint ID, with seconds_remaining and extra_radius_m), messages (array of {type,text}), last_location, checkpoints (currently active array of {id,name,clue,base_radius_m}). Poll GET every ~4 seconds to detect expiry when GPS is idle. Do not duplicate or overlap dialogue modals; queue messages and show one at a time.
